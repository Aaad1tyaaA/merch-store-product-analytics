# Future analysis

I would extend this analysis when the results can inform a new growth decision.

- **Cross-session behaviour:** a user funnel and time-to-first-purchase analysis, with censoring handled explicitly.
- **Discovery paths:** search-to-product-view conversion and common event sequences before exit or purchase.
- **Seasonality:** peak versus off-peak revenue scenarios and whether the opportunity ranking changes.
- **Products and pricing:** category order value, items per order and products frequently carted without purchase.
- **Activation thresholds:** later purchase rates by first-session product-view count.
- **Promotion adjustment:** stronger observational comparisons with overlap checks and clear limits on causal interpretation.
- **Experiment follow-through:** a prioritised test backlog and a simulated post-test readout with SRM, guardrails and intervals.
- **Reproducibility:** shared analytical-window configuration, a deterministic event sample for CI and automated memo/number checks.
- **Planner extensions:** revenue scenarios, duration curves, validated CSV import and separately tested sequential inference.
- **India-specific instrumentation:** an event plan for serviceability, COD and UPI-intent steps, grounded in an actual store's checkout.
